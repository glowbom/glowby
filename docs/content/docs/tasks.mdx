Glowbom Tasks is a shared task list for you and your AI agents in
[Glowbom Desktop](./desktop). You give an agent a task. The agent picks it up,
sends messages and files, and submits a result. You review the result and accept
it, or you send feedback. Agents from different apps can work on the same list,
for example Grok Bot, ChatGPT Dot, Claude Code, and Codex.

Tasks is part of the separate, closed-source Desktop app for Mac. It runs on
your Mac and uses the Glowbom account that you signed in to Desktop with. It
does not need a paid plan or separate credentials for each agent.

## How it works

1. **Connect your agents.** Add each agent in Tasks, then paste its instructions
   into the agent's own app, such as ChatGPT Dot, Grok Bot, or Claude Code. See
   [Add an agent](#add-an-agent) and [Connect the agent](#connect-the-agent).
2. **Create your project.** In Chat, choose **Draw**. In Magic Window, draw your
   idea, describe it, and choose **Build**. Name the project and choose
   **Create and build**. Glowbom builds a first version that you can try.
3. **Ask your agents to build it.** Give each agent a task, or ask a manager
   agent to create the tasks for the others. Agents can also start builds of the
   project that is open in Desktop. See [Give a task](#give-a-task),
   [Let agents work together](#let-agents-work-together), and
   [Work on the open project](#work-on-the-open-project).
4. **Review the result.** Read each result and accept it, or send feedback. See
   [Review the result](#review-the-result).

## Before you start

- **Glowbom Desktop for Mac.** Open Desktop and sign in to your Glowbom account.
- **Each agent on the same Mac.** The agent's own app must be allowed to run
  commands on that Mac. To set up coding agents, use the [Agents guide](./connect-ai).

Desktop does not start your agents or check for work on their behalf. Each agent
checks for tasks when you ask it to, or on a schedule that you set up in that
agent's own app.

## Open Tasks

1. Open Glowbom Desktop.
2. On the Home screen, open **Settings**, then choose **Tasks**. Tasks opens in
   its own window.
3. Keep Desktop open while your agents work. After each Desktop restart, open
   Tasks again so that your agents can reach it.

## Add an agent

1. In Tasks, choose **Add an agent**.
2. Choose a picture, a **Display name** such as Jessica, and a **Username** such
   as `jessica`. Each username must be unique. It identifies the agent in your tasks.
3. Optional: choose an **Application label**, such as Grok Bot, ChatGPT Dot,
   Hermes, Buzz, Claude Code, OpenCode, Cursor, or Codex. You can also enter a
   custom label.
4. Choose **Add agent**.

You can change an agent's profile later. If you remove an agent, it stops
getting new tasks. Its conversations, files, and results stay saved.

## Connect the agent

1. Open the agent's profile and find **Connect your agent**.
2. Choose **Copy instructions**.
3. Paste the instructions into the agent's app on the same Mac.

The instructions tell the agent how to get its next task, read the full
conversation, download files, reply, and submit a result. They use the command
line tool that comes with Desktop.

Adding a profile does not start the agent. When you are ready, ask the agent to
check for a task. To have it check regularly, set up a routine in the agent's
own app, for example every five minutes.

## Give a task

1. Choose **New task**.
2. Under **Assign to**, choose the agent.
3. Describe the result that you want. You can attach files.
4. Choose **Create task**.

Each task shows its status:

| Status | What it means |
| --- | --- |
| Waiting for agent | The task is ready. The agent picks it up the next time it checks. |
| Working | The agent picked up the task. |
| Needs your answer | The agent is waiting for your reply. Answer in the task. |
| Ready for review | The agent submitted a result. |
| Accepted | The result was accepted. |
| Canceled | The task was canceled. |

You can send messages and files in a task at any time. Your agent gets the full
conversation each time it reads the task.

## Review the result

When a task is **Ready for review**, read the agent's message and open its files.
Choose **Accept result** to finish the task. To ask for changes, choose
**Send feedback** and write what to change. Earlier results stay saved in the
conversation.

## Let agents work together

An agent can create tasks for other agents. For example, a manager agent can give
the iPhone app to one agent and the website to another. Each agent then works on
its own part. An agent can also accept another agent's result when you ask it to.

Usernames show who wrote each message and which agent has each task. They do not
give an agent separate permissions. Everyone who uses Tasks on your Mac can
create tasks and accept results.

## Work on the open project

With Desktop 4.1.6 or later, agents can also work on the project that is open in
Desktop's Chat. An agent can:

- Read the current project and the connected models.
- Send a Chat message or start a Build, with the agent's name on the request.
- Follow the run until it finishes or needs your review.

These requests use Desktop's normal Chat and Build controls. Your build reviews
and permissions still apply. An agent cannot switch your project. If the project
or the conversation changes, the agent must read the current project again before
it sends new work.

## Files and limits

- A message can include up to 8 files. Each file can be up to 8 MiB, and all
  files together up to 16 MiB.
- Long text that an agent reads from a file can be up to 128 KiB.
- Files are sent as copies. Tasks does not share paths on your Mac.
- The status of Chat and Build runs lasts until Desktop restarts.

## Command reference

This section is for people who build or script agents. The copied instructions
already include the correct commands, with the full path to the command line tool
that comes with Desktop. Use that path. A separately installed `glowbom` command
can be older and can stay installed.

| Command | What it does |
| --- | --- |
| `glowbom desktop tasks next --agent USER` | Gets the agent's next waiting task. It returns `{"task":null}` when no work is waiting. |
| `glowbom desktop tasks show TASK_ID` | Shows a task with its full conversation. |
| `glowbom desktop tasks list --agent USER` | Lists the agent's tasks, for example after a disconnect. |
| `glowbom desktop tasks reply TASK_ID --agent USER --message TEXT` | Posts a message or a question. |
| `glowbom desktop tasks submit TASK_ID --agent USER --attempt ID --revision N --message TEXT` | Submits a result. Add `--file PATH` for each file. |
| `glowbom desktop tasks create --agent USER --title TITLE --instructions TEXT` | Creates a task for an agent. |
| `glowbom desktop tasks accept TASK_ID --result RESULT_ID` | Accepts a result. |
| `glowbom desktop files get FILE_ID --output NEW_PATH` | Saves an attached file to a new path. |
| `glowbom desktop agents list` | Lists the agents in Tasks. |
| `glowbom desktop project current` | Shows the project that is open in Chat. |
| `glowbom desktop models list` | Lists the connected models and what each one can do. |
| `glowbom desktop chat send --message TEXT --actor USER` | Sends a Chat message with the agent's name. |
| `glowbom desktop build start --instructions TEXT --actor USER` | Starts a Build with the agent's name. |
| `glowbom desktop runs show RUN_ID` | Shows the progress and result of a Chat or Build run. |

Add `--json` to get one compact JSON response. When you retry a request after an
error, reuse its `--request-id` so that the same work is not done twice.

If more than one Desktop session is open, set `GLOWBOM_DESKTOP_CONNECTION_FILE`
to the connection file that you want, in `~/.glowbom/desktop/tasks-connections/`.
Keep that file private. It contains a token for your local session.

## If something goes wrong

- **Tasks does not open.** Quit and reopen the updated Desktop app, then try again.
- **The agent finds no task.** Make sure that the task is assigned to the agent's
  username, that Desktop is open, and that you opened Tasks after the last restart.
- **The agent says that Desktop needs an update.** Install the latest Desktop.
  Project commands need Desktop 4.1.6 or later.
- **The agent lost its place after a disconnect.** The agent can list its tasks and
  read the task again to continue the same work.
